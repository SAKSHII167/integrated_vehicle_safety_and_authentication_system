# Integrated Vehicle Safety and Authentication System

A face recognition-based driver authentication module developed as part of a final-year vehicle safety project.

## Features

* Face detection using OpenCV
* Face dataset collection using webcam
* LBPH-based face recognition
* Authorized/unknown driver identification
* Serial communication with ESP32
* Relay control based on authentication

## Technologies Used

* Python
* OpenCV
* NumPy
* ESP32
* Webcam

## Files

* `capture_dataset.py` – Captures and stores face images.
* `face_recognition.py` – Performs face recognition and communicates with the ESP32.

## Project Status
The face recognition module is currently implemented. Additional vehicle safety and authentication features will be integrated as the project progresses.
